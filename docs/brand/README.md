# Capwall brand kit — "Checkpoint"

A brick wall. The faint block on the left has passed through to the solid cobalt block on the right (**allow**). The red block is stopped at the wall (**deny**).

All SVG text is converted to outlines (Geist Mono SemiBold, −4.5% tracking), so the files render correctly without the font installed.

## Rules

- **Clear space:** keep at least 2/24 of the mark's height free on every side.
- **Minimum size:** full mark ≥ 20 px. Below that use `favicon.svg`, a pixel-snapped version with the faint block removed.
- **Colors:** Cobalt `#1A1AFF` (allow) · Signal red `#E5341D` (deny) · Ink `#0B0B0F` (wall) · Paper `#F4F4F0` (ground).
- **Don't:** recolor the red block to anything but red, swap the blocks' sides, add shadows or gradients, or set the wordmark in another typeface.

## Banner safe areas

LinkedIn and X overlap the bottom-left of the banner with your profile logo, so the text starts about 400 px in from the left. Keep it there if you edit the banner.
